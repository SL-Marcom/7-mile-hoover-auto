# Content intelligence helpers

This folder contains the reusable content-intelligence layer for SiteLab.

Use the exported helpers to:
- build a content blueprint for a page or asset type,
- evaluate draft copy against the Human Writing Standard,
- and preserve review requirements such as research, fact verification, trust signals, internal links, SEO compatibility, AI visibility compatibility, and approval gates.

These helpers are intentionally framework-agnostic and can be reused by future page builders, QA flows, or content review prompts.
