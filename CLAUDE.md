# Claude Code Instructions

This repository is the SiteLab website starter for cloning into local-business client websites.

- Preserve the existing stack: Next.js App Router, TypeScript, and Tailwind CSS.
- Build custom-looking sites, not generic AI templates.
- Never invent business information, reviews, ratings, awards, credentials, prices, addresses, years of experience, service areas, or guarantees.
- Use clearly marked placeholders whenever client information is missing.
- Require one clear H1 per page and unique metadata, canonicals, Open Graph data, internal links, sitemap, and robots configuration.
- Use accurate JSON-LD that matches visible page content.
- Prioritize calls, forms, bookings, and directions based on the client’s needs.
- Follow semantic HTML and accessibility standards.
- Optimize for Core Web Vitals and minimal client-side JavaScript.
- Do not deploy, publish, change DNS, add analytics IDs, or connect external services without explicit approval.
- Do not install unnecessary packages.
- Before declaring work complete, run linting, type checking, a production build, and browser-based QA.

Detailed guidance lives in .claude/rules/.
