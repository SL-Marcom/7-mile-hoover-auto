# SEO Intelligence Engine

## Purpose

This engine provides shared SEO planning and review guidance for the SiteLab operating system.

It is designed to extend the existing content-intelligence architecture rather than create a parallel workflow.

## Scope

The engine covers:
- technical SEO
- on-page SEO
- search intent alignment
- entity optimization
- semantic content structure
- internal linking strategy
- metadata generation standards
- heading hierarchy
- canonical strategy
- sitemap planning
- schema planning
- image SEO
- content overlap detection
- SEO review checklists
- approval gates

## Integration model

The SEO engine should consume the existing content intelligence blueprint where possible so SEO guidance remains aligned with the page goal, audience, brand voice, and approval requirements.

This keeps the SEO system reusable while preserving clean extension points for future AI Visibility and Local SEO engines.

## Core operating rules

- Align the page with a clear user intent.
- Use descriptive metadata and a logical heading hierarchy.
- Keep entity names, service names, and page topics consistent.
- Use internal links to support navigation and relevance.
- Only add schema when it matches the visible page content.
- Keep the page structure easy to understand for both users and AI systems.
- Treat SEO as a review requirement, not a publishing shortcut.

## Approval gates

A page should not be treated as SEO-ready until it passes:
- keyword and intent review,
- metadata review,
- internal-link review,
- schema and structure review,
- and final SEO approval.
