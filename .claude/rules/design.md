# Design Guidance

Use this repository as a reusable starter for local-business websites, not as a generic AI template factory.

- Favor custom, polished, brand-aware design over template-like layouts.
- Keep the visual language grounded in the client’s actual context, services, and geography.
- Prioritize clear hierarchy: one primary call to action, one clear H1, scannable sections, and obvious next steps.
- Use strong typography, spacing, and contrast to create a confident, trustworthy impression.
- Avoid decorative patterns or clutter that dilute the core message.
- Preserve the existing stack: Next.js App Router, TypeScript, and Tailwind CSS.
- Use the Industry Knowledge Engine's suggested tone and emphasis only as a starting direction, and confirm the final design direction against the client's actual context before treating it as final.
- Route the final design consistency check through the Reviewer/QA Engine, which records design findings as human-review items rather than an automated pass.
- Source design preferences and inspiration references from the Client Intake Engine's client-confirmed fields before treating them as design direction.
- Do not redesign or build the public-facing website in this task beyond adding repository guidance.
