# Performance Guidance

Optimize for fast, efficient experiences and minimal overhead.

- Prioritize Core Web Vitals and fast first render.
- Keep client-side JavaScript minimal and avoid unnecessary packages.
- Favor static or server-rendered approaches where appropriate.
- Optimize images and avoid oversized assets.
- Keep page complexity lean so the site remains fast on modest hosting.
- Preserve the existing project stack and avoid introducing unnecessary dependencies.
- Route the final performance check through the Reviewer/QA Engine, recording JavaScript budget, image optimization, rendering strategy, and Core Web Vitals as explicit signals rather than assumptions.
