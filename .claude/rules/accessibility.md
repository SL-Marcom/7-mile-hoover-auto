# Accessibility Guidance

Accessibility is a baseline requirement, not an afterthought.

- Use semantic HTML and meaningful landmarks such as header, nav, main, section, and footer.
- Require one clear H1 per page and a logical heading order.
- Ensure links, buttons, and form controls have clear labels and visible focus states.
- Maintain sufficient color contrast and readable text sizing.
- Provide descriptive alt text for meaningful images and avoid decorative images unless necessary.
- Make interactions keyboard accessible and avoid relying on hover alone for essential information.
- Prefer inclusive language and clear content structure.
- Route the final accessibility check through the Reviewer/QA Engine. Automated signals (H1 structure, semantic landmarks, alt text) can be recorded directly; contrast, keyboard operability, focus states, and reduced motion require an actual human-review pass, not an assumed default.
