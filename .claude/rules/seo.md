# SEO Guidance

Every page should be optimized for discoverability without sacrificing clarity or accuracy.

- Require a unique title, meta description, canonical URL, Open Graph title/description/image, and Twitter card metadata per page.
- Ensure each page has one clear H1 and a logical heading structure.
- Use relevant internal links between pages and key sections.
- Keep URLs clean and descriptive.
- Maintain a sitemap and robots configuration that reflect the live site structure.
- Use accurate JSON-LD that matches the visible page content and the page’s purpose.
- Do not add misleading structured data or keyword stuffing.
- Prefer user-focused SEO over manipulative tactics.
- Apply the SiteLab SEO Intelligence Engine for technical SEO, on-page SEO, search intent alignment, entity optimization, semantic structure, internal linking, metadata, heading hierarchy, canonical strategy, sitemap planning, schema planning, image SEO, overlap detection, review checklists, and approval gates.
- Use the SEO engine together with the Content Intelligence Engine so content goals, brand voice, and SEO requirements stay aligned.
- Use the Industry Knowledge Engine for suggested category terminology and entities, and confirm any suggested term with the client before treating it as an approved keyword or entity.
- Preserve extension points for future AI Visibility and Local SEO engines.
- Route the final SEO check through the Reviewer/QA Engine, which aggregates this engine's evaluation instead of duplicating it.
- Source entities and internal-link targets from the Client Intake Engine's client-confirmed fields, never from research-only or assumed values.
